# 🌶 Перчик

Телеграм-бот для сбора статистики по сменам. Читает чеки из топика форума
(включая статьи / Rich Messages), складывает в SQLite и отдаёт сводку
с графиками по инлайн-кнопкам.

## Возможности

Парсит чеки в свободной форме: дата и время смены, доход по каждому сайту,
токены, лайки, счётчик подписчиков. Счётчик подписчиков трактуется как снимок
на конец смены, прирост считается как разница со предыдущим снимком.
Считает статистику за произвольный период, разбивку по площадкам, цель на месяц
с прогнозом, прибыльность по дням недели и часам, доход в час по площадкам.
Раз в неделю и раз в месяц присылает отчёт сам.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python bot.py
```

## Настройка

Создать бота в @BotFather, в `/setprivacy` выставить Disable. Добавить бота
в супергруппу с включёнными топиками, дать права админа. Отправить `/id`
в нужных топиках, перенести значения в `.env`, перезапустить бота.

## Команды

| Команда | Что делает |
| --- | --- |
| `/stats` или «Перчик дай стату» | Сводка с кнопками |
| `/goal 3000` | Цель на месяц, прогресс и прогноз (`/goal 0` — снять) |
| `/when` | Прибыльность по дням недели и часам |
| `/eff` | Доход в час по площадкам |
| `/sites` | Все площадки, что встречались в чеках |
| `/last` | Последние распознанные чеки |
| `/dump` (ответом на чек) | Что бот вытащил из сообщения |
| `/forget` (ответом на чек) | Удалить чек из базы |
| `/dedupe` | Убрать дубли после импорта |
| `/report_week`, `/report_month` | Отправить отчёт вручную |
| `/id` | ID чата и текущего топика |

## Структура

| Файл | Назначение |
| --- | --- |
| `bot.py` | Точка входа, хендлеры, автоотчёты |
| `parser.py` | Разбор текста чека |
| `article.py` | Разворачивание статей Telegram в текст |
| `storage.py` | SQLite, запросы, расчёт прироста |
| `charts.py` | Графики на matplotlib |
| `keyboards.py` | Инлайн-клавиатуры |
| `config.py` | Токен, ID топиков, алиасы сайтов |

## Добавить новую площадку

Дописать алиас в `SITE_ALIASES` в `config.py`. Если площадка должна показываться
даже с нулём за период — добавить её имя в `ALWAYS_SHOW`.
